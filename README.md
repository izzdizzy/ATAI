This notebook implements a multimodal visual agent using Qwen/Qwen3-VL-8B-Instruct (4-bit quantization) for IT3103 Assignment 2. The agent follows a ReAct (Reason + Act) pattern with tools for crop_region, read_text, and calculator, and extends it with Reflexion for self-correction across multiple attempts. To run the notebook, open agent_qwen.ipynb in Jupyter or Google Colab with a GPU (the notebook uses CUDA), execute all cells from top to bottom, and wait for the model loading and inference to complete. The notebook defines 10 synthetic tasks involving bar charts and receipts, runs three approaches (Baseline direct QA, ReAct agent, and Reflexion agent), and outputs a comparison table showing accuracy for each method. Known issues: the ReAct and Reflexion agents show lower accuracy than baseline in the saved outputs because the model struggles to properly invoke the finish tool within max_steps, often hitting the step limit; additionally, the 'finish' tool is not registered in TOOL_FNS so when the model calls it, an error is returned.
